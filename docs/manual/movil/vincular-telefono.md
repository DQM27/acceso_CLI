# Vincular el teléfono por primera vez

## Para qué sirve

Dejar listo un teléfono nuevo (o con la app reinstalada) para trabajar en
el puesto de control. Al vincularlo se traen los contratistas, empresas,
gafetes y usuarios de la unidad, y con eso ya se puede iniciar sesión.

## Quién puede hacerlo

Cualquier persona con el teléfono en la mano, pero necesita el **código de
vinculación**, que **sólo genera un administrador en el panel web**.

## Dónde

La pantalla **Vincular este teléfono** aparece sola al abrir Lattis cuando
el teléfono todavía no tiene datos. Si ya está vinculado, se abre
directamente el inicio de sesión.

## Pasos — con el código QR (lo más rápido)

1. Pida al administrador el código QR del panel para este teléfono.
2. Abra Lattis. Verá **Vincular este teléfono**.
3. Toque **Escanear código QR**. Si la app pide permiso para usar la
   cámara, toque **Dar permiso**.
4. Apunte al código QR que muestra el panel. Al leerlo, el marco se pone
   verde.
5. Verá **Sincronizando** ("Descargando contratistas, empresas, gafetes y
   usuarios de la unidad. No cierre la app."). Espere sin cerrar la app.
6. Verá **Teléfono vinculado** ("Quedó registrado en (unidad). Ya puede
   iniciar sesión."). Siga con [Iniciar sesión](iniciar-sesion.md).

## Pasos — escribiendo el código

1. En **Vincular este teléfono** (o en la cámara del QR), toque **Escribir
   el código**.
2. Escriba el código en **Código de vinculación**. Tiene la forma
   **XXXX-XXXX-XX**.
3. Toque **Vincular con este código** y siga desde el paso 5 de arriba.

Tenga en cuenta:

- El código **sirve una sola vez** y **vence en pocos minutos**.
- Hace falta **internet**.

## Mensajes que pueden aparecer

| Mensaje | Qué significa | Qué hacer |
|---|---|---|
| "El código no es válido o ya venció -- pida uno nuevo en el panel" | El código está mal, ya se usó o venció. | Pida un código nuevo al administrador. |
| "No se pudo conectar con la nube, intente de nuevo" | Sin internet o el servidor no respondió. | Revise la conexión (datos o wifi) y vuelva a intentar. |
| "La clave de este equipo ya está vinculada a otro dispositivo -- pida ayuda a un administrador" | El panel ya tiene registrado este teléfono como otro dispositivo. | Avise a un administrador. |
| "Esta versión de la app ya no es compatible -- actualice la app para seguir sincronizando" | La app instalada es demasiado vieja. | Pida al administrador la versión nueva. |
| "Se necesita permiso de cámara para leer el código QR del panel." | La app no tiene permiso para la cámara. | Toque **Dar permiso** (o **Abrir Ajustes** y active la cámara para Lattis). O escriba el código a mano. |
