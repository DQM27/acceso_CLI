# Vincular el equipo por primera vez

## Para qué sirve

Dejar listo un equipo nuevo (o reinstalado) para trabajar en el puesto de
control. Al vincularlo se traen los contratistas, empresas, gafetes y
usuarios del sitio, y con eso ya se puede iniciar sesión.

## Quién puede hacerlo

Cualquier persona frente al equipo, pero necesita un **código de
vinculación**. El código **sólo lo genera un administrador, en el panel
web**: pídaselo a él. Desde el escritorio no se puede sacar.

## Dónde

La pantalla **Vincular este equipo** aparece sola al abrir el programa
cuando el equipo todavía no tiene datos. Si el equipo ya está vinculado, se
abre directamente la pantalla de inicio de sesión.

## Pasos

1. Pida al administrador el código de vinculación para este equipo. Tiene
   la forma **XXXX-XXXX-XX**.
2. Abra el programa. Verá **Vincular este equipo**.
3. Escriba el código en **Código de vinculación**. Los guiones se ponen
   solos.
4. Pulse **Vincular y sincronizar**. Mientras trabaja dice **Vinculando…**.
5. Al terminar aparece la pantalla de inicio de sesión: ver
   [Iniciar sesión](iniciar-sesion.md).

Tenga en cuenta:

- El código **sirve una sola vez** y **vence en pocos minutos**. Úselo
  apenas se lo den.
- Hace falta **internet** para vincular.
- El botón **Vincular y sincronizar** no se activa hasta que el código
  esté completo.

## Mensajes que pueden aparecer

| Mensaje | Qué significa | Qué hacer |
|---|---|---|
| "El código no es válido o ya venció -- pedí uno nuevo en el panel" | El código está mal escrito, ya se usó o pasaron demasiados minutos. | Revise el código. Si está bien, pida uno nuevo al administrador (lo genera en el panel). |
| "No se pudo conectar con la nube, intentá de nuevo" | El equipo no tiene internet o el servidor no respondió. | Revise la conexión y vuelva a pulsar **Vincular y sincronizar**. Si el código venció mientras tanto, pida otro. |
| "La clave de este equipo ya está vinculada a otro dispositivo -- pedí ayuda a un administrador" | El panel ya tiene registrado este equipo como otro dispositivo. | Avise a un administrador. |
| "Esta versión de la app ya no es compatible -- actualizá para seguir sincronizando" | El programa instalado es demasiado viejo. | Instale la versión nueva (pida el instalador a un administrador) y vuelva a intentar. |
