# Buscar ayuda en el manual (F1)

## Para qué sirve

Leer este manual dentro del programa: cómo se hace cada cosa y qué
significa cada mensaje. Funciona también sin internet.

## Quién puede hacerlo

Cualquier usuario con sesión abierta.

## Dónde

- Atajo **F1**, desde cualquier pantalla.
- O la sección **Ayuda** del menú lateral.

## Pasos — buscar

1. Pulse **F1**. Se abre **Ayuda** con el cursor en el buscador.
2. Escriba una o dos palabras (por ejemplo, **gafete perdido** o
   **PRAIND**), o pegue el mensaje que le apareció en pantalla.
3. Debajo aparecen los temas que coinciden, con el trozo donde aparece la
   palabra.
4. Pulse un tema (o **Enter** para el primero). Se abre a la derecha, en la
   parte donde está lo que buscó.
5. Para borrar la búsqueda y volver a la lista de temas, pulse **Esc**.

No hace falta escribir tildes ni mayúsculas.

## Pasos — recorrer los temas

1. Sin nada escrito en el buscador, a la izquierda está la lista de temas
   agrupada como este manual.
2. Pulse un tema para leerlo.
3. Los textos subrayados llevan a otro tema relacionado. Para regresar,
   pulse **Atrás**, arriba del tema.

## Mensajes que pueden aparecer

| Mensaje | Qué significa | Qué hacer |
|---|---|---|
| "No hay nada con esas palabras" | Ningún tema tiene lo que escribió. | Pruebe con menos palabras, o con otras más cortas (por ejemplo, «gafete» o «salida»). |
