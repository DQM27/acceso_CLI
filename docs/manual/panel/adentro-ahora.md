# Adentro ahora

## Para qué sirve

Ver quién está adentro en este momento **en todas las unidades**:
contratistas, proveedores, gafetes provisionales KOF y visitas por correo.
Sirve para el control diario, para un conteo de emergencia y para detectar
salidas que se olvidaron registrar.

## Quién puede hacerlo

Administradores del panel. Es sólo de consulta.

## Dónde

**Adentro ahora**, en el menú lateral.

## Qué se ve

| Columna | Qué muestra |
|---|---|
| Unidad | Dónde está la persona |
| Tipo | Contratista, proveedor, gafete KOF o por correo |
| Cédula / código | Cédula, o código de empleado en KOF |
| Nombre | Nombre de la persona |
| Empresa / motivo | La empresa, o el motivo en las visitas por correo |
| Gafete, Placa | Si tiene |
| Entrada | Cuándo entró |
| Tiempo adentro | Cuánto lleva (por ejemplo, "3 h 20 min") |
| Dio ingreso | Quién registró la entrada |

Quien lleva **más de 12 horas adentro** aparece **en rojo**: probablemente
salió sin que le registraran la salida. Avise a esa unidad.

Use el buscador ("Cédula, nombre, gafete…") o los filtros por columna para
acotar. La lista se actualiza sola.

Las salidas se registran en el puesto de control (escritorio o teléfono),
no desde aquí.
