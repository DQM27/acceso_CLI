Dos formas de activar un dispositivo

Hoy, pegar el secreto correcto alcanza para que un dispositivo quede activado al instante. Esta página compara ese mecanismo contra una variante con verificación por correo que se evaluó y se pospuso (ver docs/pendientes.md) — para decidir, con el dibujo delante, si vale la pena la fricción extra.

Hoy: el secreto solo alcanza

En producción

Costo: ninguno — cero pasos extra. Riesgo: si el secreto se filtra completo (screenshot, archivo compartido, backup mal subido), quien lo tenga puede activarlo de inmediato, sin que nadie se entere hasta revisarlo a mano.

Propuesto: código por correo en la primera activación

Evaluado y pospuesto

Costo: un correo + escribir un código, una única vez por activación (no en cada sincronización). Gana: un secreto filtrado, solo, ya no alcanza — hace falta también acceso al correo del admin en ese mismo momento.
